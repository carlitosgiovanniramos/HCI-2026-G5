# Consentimiento informado · Prueba de usabilidad del Dashboard 2.0

**Responsable de este documento:** Allison Cobos
**Grupo 5 · Interacción Persona-Ordenador · UTA · Paralelo 5A**
**Se usa en:** pilotaje del APE 6 (Fase 2), con los participantes P1, P2 y P3.

## Qué es esta actividad
Estamos evaluando el **Usability Test Dashboard 2.0**, una aplicación web para gestionar pruebas de usabilidad. Le pediremos realizar **tres tareas** en la aplicación mientras dice en voz alta lo que piensa. Al final responderá un cuestionario corto. La sesión dura aproximadamente **20 minutos**.

## Lo que debe saber
- **Se evalúa la aplicación, no a usted.** No existen respuestas correctas o incorrectas.
- Su participación es **voluntaria**. Puede detenerse o retirarse en cualquier momento, sin ninguna consecuencia.
- Registraremos: si completa cada tarea, el tiempo, los errores, sus comentarios y un cuestionario de 10 preguntas (SUS).
- Sus datos se **anonimizan**: se le identificará solo con un código (P1, P2 o P3). Su nombre no aparecerá en ningún archivo ni en GitHub.
- **Grabación de pantalla:** solo si usted lo acepta. Se graba **únicamente la pantalla**, sin cámara ni audio. El video no se publica en GitHub ni en ningún otro lugar; se guarda en una carpeta privada del grupo y solo sirve para revisar tiempos y errores. Si no acepta, la prueba se hace igual, sin grabar.
- Los resultados se usan únicamente para la asignatura y para mejorar la aplicación.
